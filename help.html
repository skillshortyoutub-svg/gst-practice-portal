Help — module guides

Short summaries of how each workflow runs on the official GST portal, and how this practice site simulates it. For full details always read the official user manuals (links open the official GST tutorial site). This site is a training simulator only; amounts, due dates and rules here are simplified.

1. New Registration (REG-01) & Track Application Status

  1. Services › Registration › New Registration. Part A: I am a, State/UT, District, Legal Name (as per PAN), PAN, Email and Mobile of the Primary Authorized Signatory, captcha.
  2. Separate OTPs to mobile and email (valid 10 minutes) → TRN is generated.
  3. Login with TRN (+captcha) → single OTP → My Saved Applications (status Draft, expires in 15 days) → Edit.
  4. Part B tabs: Business Details, Promoter/Partners, Authorized Signatory, Authorized Representative, Principal Place of Business, Additional Places of Business, Goods and Services, State Specific Information, Aadhaar Authentication, Verification. Use SAVE & CONTINUE; a tick and % completion show progress. Bank account is added after grant via non-core amendment.
  5. Verification: declaration, name of authorized signatory, place → submit with DSC / E-Signature / EVC (only EVC is simulated). Status becomes Pending for Validation; after Aadhaar authentication the ARN is generated (Pending for Processing).
  6. Services › Registration › Track Application Status (ARN/TRN). In this practice site you can simulate the officer's Approve (GSTIN + temporary password) or Reject.

Practice validations: PAN format & holder type vs Constitution, mobile/email/PIN/IFSC formats, DIN mandatory for companies, age 18+, file size limits, Rule 14A requires Aadhaar = Yes, GSTIN with correct check digit.

Official manuals: Apply for Registration (Normal Taxpayer) · Track Application Status · Registration user guide index

2. Login and First Time Login

  1. Login › "First time login: click here" → enter GSTIN (or Provisional ID) and the temporary password received by email, plus captcha.
  2. New Credentials: create Username (8-15 chars) and Password (8-15 chars with upper, lower, number, special) and re-confirm.
  3. Login with the new credentials. You are prompted to file a non-core amendment to add Bank Account details (here: Registration › Amendment of Registration (Non-Core)).

Official manual: First Time Login

3. GSTR-1 and IFF

  1. Services › Returns › Returns Dashboard → select Financial Year, Quarter, Period → SEARCH → GSTR-1 tile › PREPARE ONLINE.
  2. Add records in tables: 4A/4B/6B/6C (B2B), 5 (B2C Large: inter-State to unregistered, invoice value above ₹1 lakh), 7 (B2C Others, consolidated), 9B (Credit/Debit notes to registered), 12 (HSN summary) and 13 (documents issued) are compiled automatically here.
  3. Generate summary → declaration → select authorized signatory → FILE WITH DSC/EVC → ARN; status Filed. Filed data cannot be edited (amend in a later period).
  4. Quarterly (QRMP) taxpayers can use the optional IFF in months 1 and 2 of a quarter for B2B invoices and notes, and file the quarterly GSTR-1 in month 3.

Due dates used here: GSTR-1 monthly 11th, quarterly GSTR-1 and IFF 13th of the next month.

Official manuals: GSTR-1 · IFF · Returns user guide index

4. GSTR-3B (with payment of tax)

  1. Returns Dashboard → GSTR-3B tile › PREPARE ONLINE. Tables 3.1 and 3.2 are auto-drafted from filed GSTR-1/IFF (ITC in Table 4 comes from GSTR-2B on the real portal; here you enter it).
  2. Fill 3.1 (outward & reverse-charge inward), 3.2 (inter-State to unregistered), 4 (Eligible ITC: A, B reversals, C net), 5 (exempt inward), 5.1 (interest & late fee, system computed).
  3. SAVE GSTR-3B → PREVIEW DRAFT → PROCEED TO PAYMENT → Table 6.1 shows ITC utilisation and cash needed. If cash is short: CREATE CHALLAN, pay, return. Then MAKE PAYMENT / POST CREDIT TO LEDGER (cannot change the return after this).
  4. Declaration → authorized signatory → FILE GSTR-3B WITH DSC/EVC → ARN, status Filed. View under Services › Returns › Track Return Status.

ITC order (sec 49/49A/49B): IGST credit first for IGST, then CGST/SGST; CGST credit for CGST then IGST; SGST credit for SGST then IGST; no CGST↔SGST cross-use. Reverse-charge tax, interest and late fee are paid in cash. Late fee: ₹25/day CGST + ₹25/day SGST (₹10 each for nil), capped by turnover as per Notification 19/2021-CT (see section 12); interest 18% p.a. on tax paid in cash, auto-computed in Table 6.1.

Official manuals: Create and Submit GSTR-3B · Track Return Status

5. Create Challan (PMT-06), payment and Electronic Ledgers

  1. Services › Payments › Create Challan. Quarterly filers first pick a Reason for Challan: Monthly payment for quarterly return (35% challan or self-assessment) or Any other payment.
  2. Details of Deposit: amount per major head (IGST, CGST, SGST/UTGST, Cess) and minor head (Tax, Interest, Penalty, Fee, Others). Total and amount in words are shown.
  3. Payment modes: E-Payment (Net Banking, Card, UPI), Over the Counter (up to ₹10,000), NEFT/RTGS → GENERATE CHALLAN → CPIN (valid 15 days).
  4. After payment a CIN is generated and the Electronic Cash Ledger is credited. Track via Services › Payments › Track Payment Status (GSTIN + CPIN).
  5. Ledgers: Electronic Cash Ledger (major × minor heads, no cross-utilisation), Electronic Credit Ledger (ITC), Electronic Liability Ledger (return-related liabilities, debited on filing, credited on payment/offset).

Official manuals: Create Challan (Post Login) · Electronic Cash Ledger · Payments user guide index

6. Composition taxpayers — CMP-08 and GSTR-4

  1. Choose Option for Composition = Yes and a category in Part B › Business Details during registration.
  2. Each quarter file CMP-08 (statement for payment of self-assessed tax) by the 18th of the month after the quarter: outward turnover × composition rate (split CGST/SGST) plus reverse-charge tax. Paid from cash only (no ITC).
  3. File the annual GSTR-4 after the financial year (here: select March in the Returns Dashboard; due 30 April).

Practice rates: manufacturers/traders 1%, restaurants 5%, section 10(2A) service providers 6%.

Official reference: GST portal Help › Returns (CMP-08 & GSTR-4 manuals)

7. Search Taxpayer

  1. Search Taxpayer › Search by GSTIN/UIN (with captcha before login): shows Legal Name, Trade Name, Effective Date of registration, Constitution, GSTIN status, Taxpayer type, Administrative office, Principal place of business, Nature of business activities, and SHOW FILING TABLE.
  2. Search by PAN lists all GSTINs on that PAN; Search Composition Taxpayer shows the opt-in status.

Official manual: Search Taxpayer

8. GSTR-2A and GSTR-2B (inward supplies & ITC)

  1. Services › Returns › Returns Dashboard (here: Returns › GSTR-2A / 2B) → choose the period.
  2. GSTR-2A is a dynamic view of documents your suppliers report in their GSTR-1/IFF; it changes whenever they file.
  3. GSTR-2B is a static monthly ITC statement (generated on the 14th of the next month on the real portal) showing ITC availability per document. Here you click GENERATE GSTR-2B.
  4. ITC is shown as not available for reverse-charge documents and where CGST/SGST is charged but the place of supply is another State (POS rule).
  5. Compare ITC as per 2B with Table 4A(5) of GSTR-3B; claiming more than 2B is flagged. "Use GSTR-2B ITC" copies the 2B values into the 3B draft; new 3B drafts pick them up automatically.
  6. To see real supplier data in practice, register a second dummy GSTIN in this browser, file its GSTR-1 with your GSTIN as recipient, or press GENERATE SAMPLE SUPPLIER DATA.

Official manuals: View and download GSTR-2B · GSTR-2A

9. Amendments in GSTR-1 (Table 9A and 9C)

  1. Open GSTR-1/IFF of the current period and choose Table 9A (amended B2B invoices) or 9C (amended credit/debit notes).
  2. Pick the original document; it must be in an earlier period whose GSTR-1/IFF is filed. Edit the revised GSTIN, number, date, POS, rate or value.
  3. Only the difference in tax is added to (or reduced from) the current period's liability and flows to GSTR-3B. The recipient sees it as B2BA / CDNRA in GSTR-2A/2B.
  4. Practice time limit: up to 30 November following the end of the original financial year (or the annual return, if earlier). Each original can be amended once here.

Official manual: GSTR-1 (includes amendment tables)

10. e-Invoice (IRN)

  1. The taxpayer prepares the invoice in the standard schema and reports it to an Invoice Registration Portal (IRP).
  2. The IRP validates it and returns a 64-character IRN (hash of supplier GSTIN, financial year, document type and document number), an Ack No. and date, and a digitally signed QR code. The data flows to GSTR-1 and to the e-way bill system.
  3. Duplicates are rejected: the same document number cannot be reported twice in a financial year, even after cancellation.
  4. Cancel IRN only within 24 hours of generation, with a reason (Duplicate, Data entry mistake, Order cancelled, Others) and remarks, and only if no active e-way bill exists. After 24 hours, issue a credit note or amend in GSTR-1.

Practice notes: the QR code here is a placeholder drawing, not a real signed QR. Use "simulate 25 hours passed" to see the 24-hour rule.

Official references: e-Invoice web user manual (PDF) · e-invoice system overview (PDF)

11. e-Way Bill

  1. Part A: transaction type, sub type, document type/number/date, bill-from and bill-to GSTIN (URP for unregistered), PINs, goods (HSN, quantity, taxable value, tax rate), transporter ID and approximate distance (max 4,000 km; up to 100 km if both PINs are the same).
  2. Part B: mode (Road/Rail/Air/Ship) and vehicle number or transport document number. Without Part B, the e-way bill is not valid for movement.
  3. Validity: 1 day per 200 km (20 km for Over Dimensional Cargo). The first day ends at midnight of the following day.
  4. Update Part B to change the vehicle (reasons: break down, transhipment, others); validity does not restart. Cancel within 24 hours if not verified in transit. Extend validity within 8 hours before or after expiry, giving a reason and the remaining distance.
  5. From an e-Invoice you can generate the e-way bill directly (Part A is pre-filled).

Practice notes: the general threshold is a consignment value above ₹50,000; state-specific rules are not modelled.

Official references: e-Way Bill system documentation (release notes: 200 km/day validity) · e-Invoice manual, section 14: Generate EWB from IRN

12. Cut-offs, thresholds and late fees (checked against official sources, Oct 2026)

  • GSTR-2B is generated on the 14th of the next month. It contains documents filed by suppliers from 00:00 on the 12th of the month to 23:59 on the 11th of the next month (monthly GSTR-1), or from the 14th to the 13th (IFF / quarterly GSTR-1). Later filings go to the next GSTR-2B. Source: GSTR-2B FAQ (tutorial.gst.gov.in)
  • e-Invoice 30-day limit: from 1 April 2025, taxpayers with AATO of ₹10 crore and above cannot report invoices / credit notes / debit notes older than 30 days on the IRP. No such limit below ₹10 crore. IRN can be cancelled within 24 hours. Source: GSTN advisory (einvoice1.gst.gov.in), advisory no. 543 of 5 Nov 2024
  • e-Way Bill thresholds: ₹50,000 for inter-State movement (Rule 138, CBIC). Intra-State ₹1 lakh in Delhi, Maharashtra, Tamil Nadu, Bihar, MP (inter-district) and Rajasthan (₹2 lakh within a city); ₹50,000 in West Bengal (since 1 Dec 2023), Karnataka, Gujarat, UP. State limits cross-checked with published compilations (IndiaFilings, Busy) — not each State notification; specified goods may have lower limits.
  • e-Way Bill distance: auto-calculated from PIN codes, up to 10% more allowed. Same PIN: up to 100 km. This site uses a small dummy PIN table.
  • GSTR-3B late fee (Notification 19/2021-CT, from June 2021): ₹25/day CGST + ₹25/day SGST (₹10 + ₹10 for nil returns). Maximum per Act: nil ₹250; turnover up to ₹1.5 crore ₹1,000; ₹1.5-5 crore ₹2,500; above ₹5 crore ₹5,000 (each for CGST and SGST). Interest 18% p.a. on tax paid in cash after the due date (Sec 50). Source: Notification 19/2021-CT (gstcouncil.gov.in)
  • GSTR-9: due 31 December after the FY; optional up to ₹2 crore. Late fee per day (CGST + SGST equal): up to ₹5 crore ₹25 (max 0.02% of State turnover); ₹5-20 crore ₹50 (max 0.02%); above ₹20 crore ₹100 (max 0.25%), FY 2022-23 onwards. Source: Notification 07/2023-CT (gstcouncil.gov.in)

14. Registration amendment, cancellation and revocation

  • Core fields (legal name without PAN change, principal/additional place of business, partners/directors) → REG-14, officer approval REG-15. Non-core fields (trade name, contact, bank, HSN) are auto-approved.
  • Cancellation REG-16 → order REG-19. Pay tax on closing stock; file final return GSTR-10 within 3 months.
  • Revocation REG-21 → order REG-22, within 90 days of cancellation order (extendable); file pending returns first.

Official manual: Registration user manuals

15. Refund (RFD-01) and LUT (RFD-11)

  • LUT allows export / SEZ supply without paying IGST; file once per FY.
  • Refund of accumulated ITC on export under LUT: Rule 89(4) formula = zero-rated turnover × Net ITC ÷ Adjusted total turnover.
  • Refund of excess cash ledger balance: the claimed amount is debited from the cash ledger on filing; RFD-02 acknowledgement, RFD-06 sanction order (re-credit by PMT-03 if rejected).

Official manual: Refund user manuals

16. TDS / TCS (GSTR-7, GSTR-8) and credit received

  • GSTR-7: TDS 2% (1% + 1% or 2% IGST) where contract value exceeds ₹2.5 lakh; due 10th.
  • GSTR-8: TCS by e-commerce operators 0.5% (from 10 July 2024; earlier 1%); due 10th.
  • Supplier accepts the credit in "TDS and TCS Credit Received" → credited to the cash ledger.

Official manuals: Returns user manuals

17. ITC-04 (job work)

Report goods sent to and received back from job workers. Half-yearly (AATO > ₹5 crore, due 25 Oct / 25 Apr) or annual (due 25 April). Inputs to return in 1 year, capital goods in 3 years.

18. GSTR-9 and GSTR-9C

GSTR-9C (self-certified reconciliation with audited accounts) is required when aggregate turnover exceeds ₹5 crore; file after GSTR-9.
